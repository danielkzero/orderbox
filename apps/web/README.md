# OrderBox Web

Aplicação Laravel responsável pelo painel Blade e pela API utilizada pelo Mobile.

## Stack

- Laravel 12;
- Blade e Breeze;
- Laravel Sanctum;
- MariaDB;
- Tailwind CSS e Vite.

## Configuração

Consulte [Ambiente de Desenvolvimento](../../docs/07-desenvolvimento/getting-started.md).

## Verificações

```text
vendor/bin/pint --test
php artisan test
npm run build
```
