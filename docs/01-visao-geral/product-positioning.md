# O que é o OrderBox

O OrderBox não é um ERP.

O OrderBox é uma plataforma de força de vendas.

Seu objetivo é conectar:

- Representantes
- Clientes
- Produtos
- Pedidos

de forma simples, online e offline.

O ERP do cliente continua sendo responsável por:

- Financeiro
- Fiscal
- Faturamento
- Estoque avançado
- Contabilidade

O OrderBox complementa o ERP ao oferecer uma experiência comercial focada em representantes, clientes, catálogo e pedidos.

Na V1, o estoque disponível é apenas consultado a partir de dados sincronizados do ERP. O OrderBox não mantém o saldo oficial nem registra movimentações.
