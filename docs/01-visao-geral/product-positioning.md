# O que é o OrderBox

O OrderBox não é um ERP.

O OrderBox é uma plataforma de força de vendas.

Seu objetivo é conectar:

- Representantes
- Clientes
- Produtos
- Pedidos

de forma simples, online e offline.

O ERP do cliente continua sendo responsável por:

- Financeiro
- Fiscal
- Faturamento
- Estoque avançado
- Contabilidade
